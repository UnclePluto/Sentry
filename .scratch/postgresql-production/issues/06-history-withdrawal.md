# 06 — 提交历史与整批作废闭环

**What to build:** 管理员按整份提交分页查看历史，并在权限范围内作废整批结果；历史可追溯，大盘贡献只扣除一次。

**Blocked by:** 04 — 确认入库与大盘总览闭环

**Status:** complete

- [x] 历史列表分页且有响应上限，显示提交人、报告日期、地区、原有效汇总、提交状态及作废审计，不提供逐条检测明细或原 Excel 下载。
- [x] 普通管理员只能读取和作废本人批次，超管管理全部；服务端强制权限，提交人身份不能由客户端伪造。
- [x] 账号停用、删除或改名不丢失历史归属快照；当前无权限账号不能发起新作废或借重试越权。
- [x] 作废原子改变有效状态及汇总贡献，重复作废不重复扣数；作废后不恢复任何跨上传旧版本，也不能重新发布同一已作废批次。
- [x] 确认中批次的作废请求有明确状态响应，不允许与发布事务形成“已作废但仍新增贡献”的结果。
- [x] 总览及已落地的汇总读取能够排除该批次全部贡献，小数据下验证成功后 30 秒内更新；与第 05 票的全维度联验在迁移核对及最终验收覆盖。
- [x] 原检测明细及已提交／已作废历史长期保留，不通过物理删除结果实现作废。
- [x] 真实 HTTP 和浏览器覆盖本人／全部列表、分页、权限拒绝、整批作废、重复作废、审计保留和重启后状态一致。
