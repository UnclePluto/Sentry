# SENTRY 病原体流行监测平台

Excel 异步上传与校验 → PostgreSQL 标准化存储及持久化汇总 → 立体地图和统计大盘。数据库迁移、备份和部署见 [PostgreSQL 运维手册](deploy/POSTGRESQL.md)。生产已于 2026-09-16 切换 PostgreSQL，武汉 OSS 备份与隔离恢复已验证。

## 启动

需要 Node.js 22.13+（生产镜像使用 Node.js 24）、npm 和 PostgreSQL 17。先创建数据库，在私有 `.env` 配置 `DATABASE_URL`；运行身份与迁移身份的分离方式见运维手册。

```bash
npm ci
npm run db:migrate
npm run dev:all
```

展示大屏：http://127.0.0.1:3000 。上传与数据管理：http://127.0.0.1:3002 （未登录时进入 `/login`）。两个入口独立，大屏无管理入口，也不转发管理接口或写入请求。

内部渲染服务位于 `127.0.0.1:3010`，数据服务位于 `127.0.0.1:3001`，只供本机入口转发。院内对外只代理所需的展示或管理入口。

生产构建与本机启动：

```bash
npm run build
npm start
# 另一个进程（生产 Compose 已独立配置）
npm run worker
```

使用 `dev:all` 或 `start` 启动完整的双入口平台。`npm run api` 仅用于单独调试数据服务，不要在完整平台已运行时重复启动。

## 使用

1. 管理员登录后台，在“上传结果”选择省份、城市和检测日期（默认当天）；区县可选，不需要机构或坐标。
2. 上传 `.xlsx`，点击“解析并预览”，文件受理后后台排队处理，关闭页面也可从任务列表找回结果。只读取 Sheet1，先剔除 CT 为 `-`／`—` 或病原体为 N 的对照行，再校验有效记录。
3. 核对有效结果行、有效试剂、阳性试剂、剔除行数及阳性率，点击“确认提交”。确认前不参与统计；确认后异步入库，可持续查看状态。
4. 在“我的提交记录”查看本人历史；超管看到“全部提交记录”。错误或误重复上传通过“作废整批”处理，保留原汇总、作废时间及操作人。
5. 打开大盘“监测数据”，或访问 http://127.0.0.1:3000/?source=real 。按检测日期与病原体筛选，点击地图下钻。大盘每 20 秒刷新，作废后的下一次查询即排除该批次。

演示数据独立标识，不混入真实统计。前后台入口完全分离。

## 后台账号与登录

首次启动自动创建唯一的超级管理员 `superadmin`，随机密码保存在 `data/initial-admin.json`（仅当前系统用户可读写，不进入版本管理）。初始化不会覆盖已有账号。可在首次部署前设置 `SENTRY_BOOTSTRAP_PASSWORD` 指定不少于 12 位的初始密码；账号创建后此变量不再改变密码。

超管可通过“管理员账号”新增、停用、启用、删除普通管理员或重置其密码；超管自身不能被删除、停用或代重置。所有管理员可通过顶部“修改密码”修改自己的密码。超管修改密码后自动移除初始密码文件。

密码使用独立随机盐与 scrypt 散列存储。会话使用 HttpOnly、SameSite=Strict Cookie，有效期 8 小时；数据库仅存会话令牌摘要。退出、停用、重置/修改密码及删除账号会撤销相应会话。账号连续失败 8 次后暂缓登录 15 分钟。管理员权限在 API 层强制校验，未登录无法访问提交历史或写入接口；管理员只管理本人提交，超管可管理全部。

## 已确认的数据口径

- 检测批次号为 Excel 的 `batch`，试剂标识为 `sam`，病原体代码为 `PathogenWithReads`，中文列为翻译。业务上传批次号由系统独立生成。
- CT 为 `-`／`—` **或**病原体为 `N`，整行剔除。剩余记录的有限数值 CT 为阳性，“阴性”为阴性；空白和非法 CT 阻止整份提交，不设置临床 CT 阈值。
- 只在本次上传的有效行内检查 `batch + sam + 病原体` 重复。无论 CT 相同或冲突，都提示行号并要求修正；不同病原体允许共享 `batch + sam`。全部为对照或零有效数据不能提交。
- 同一上传批次内按 `batch + sam` 统计有效试剂；任一病原体阳性即计为阳性试剂。总览阳性率 = 阳性试剂数 / 有效试剂数。各病原体分别计数，不推定缺失行是阴性。
- 各上传批次独立累计，不跨提交去重、覆盖或按最新日期选择版本。误重复上传需要整批作废。同一预览重复确认不重复累计。
- 检测日期由提交人选择，整份文件共用；提交时间系统自动记录。大盘按检测日期筛选，历史分别显示两者。
- 至少选到市，区县可选。全国及省级视图包含市级和区县级提交；进入市内区县分布时，排除未填写区县的提交。地图及两侧图表使用同一地区数据集合；返回上级恢复完整汇总。
- 直辖市的城市选择使用直辖市本身，在区县分布视图同样剔除仅到市的数据。区县不再下钻机构点位。
- 提交归属来自登录会话。普通管理员仅能查看和作废本人提交，超管可管理全部；账号删除不删除历史的提交人快照。
- 已作废的整批数据退出统计，保留历史汇总与作废操作人、时间；不会恢复其他版本。

## Excel 支持

只识别 Sheet1 首 10 行中的表头：`batch`、`sam`、`PathogenWithReads`、`CT value`，可选 `中文`，保留已有表头别名。其他工作表完全忽略，不能作为数据或字典来源。缺少 Sheet1 或必填列明确报错。

最大 8 MiB、Sheet1 最多 30,000 个非空数据行（含对照，不含表头）；独立工作进程内的解析线程限时、限内存，并在解压前检查 ZIP 展开大小。原 Excel 仅私有暂存，解析完成、校验失败或取消后删除；异常最长 24 小时清理。结构化预览保留 7 天，逾期清理明细但保留任务摘要。预览和历史只返回汇总，不提供逐条检测明细或原文件下载。

参考样表按新规则：Sheet1 共 378 条结果，剔除 84 行，剩余 294 条有效结果、199 个有效试剂、199 个阳性试剂，阳性率 100%。这是剔除 N 阴性和横线对照后的结果，与旧口径的分母不同。

## 数据与升级

- PostgreSQL 是唯一运行数据库；必须设置 `DATABASE_URL` 或只读的 `DATABASE_URL_FILE`，不自动回退 SQLite。`SENTRY_DATA_DIR` 只用于私有暂存及初始账号文件。
- 提交保存地区、归属、日期、汇总及作废审计，正式数据长期保留。任务持久化于 PostgreSQL，无 Redis 依赖；工作进程具有租约、有界重试、取消和过期清理。
- 发布、作废和汇总版本在事务中生效，大盘从持久化批次贡献聚合，不将全部检测明细加载到 Node.js。
- SQLite 仅作为离线迁移来源和受控旧版本回退来源。迁移命令先制作一致性快照，写入空的隔离 PostgreSQL 并核对统计；保留账号密码哈希及历史标识，不原地改写在线库。
- 发布新库写入后，不允许简单退回旧 SQLite 丢弃新写入；具体维护切换门槛见运维手册。
- 规格与任务位于 `.scratch/postgresql-production/`；验收及未完成事项见 [实施记录](.scratch/postgresql-production/implementation-report.md)。

## 技术与地图

React + TypeScript / Vinext；shadcn/ui 后台；ECharts 趋势、热力图；deck.gl 直接绘制离线行政区和立体数据图层；Node.js HTTP API + 独立工作进程 + PostgreSQL。地图不依赖在线底图、地图密钥或外部字体。

地图边界来源：[阿里云 DataV GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)，缓存位于 `public/maps/`。已缓存全国及主要省市的 363 份边界文件，区县轮廓从城市缓存提取。台湾省当前只有全国底图中的省级轮廓，缺少下级边界。已下载区域在断网时可用；联网后执行 `npm run maps` 可补充或重试未下载边界。

大屏采用青紫色科技风格，地图铺满展示区域，指标、趋势、热力图以两侧悬浮面板呈现。左侧压缩总览并完整列出检出排行（超长列表可滚动），右侧扩大时空分布图；化学装饰、共检出观察模块与底部小字已移除。

地图分级颜色表示试剂阳性比例区间，不是疫情风险等级。区域数据随月份变化时，板块平滑调整到新阳性率对应的高度，并以紫色边缘临时强调；青色脉冲为每 3.4 秒一次的区域轮巡，即使暂停月份仍运行。板块高度仅与当前阳性率成比例关联，数据不变时保持高度；轮巡、悬停和临时高亮不再增加高度或导致回落。高度不表示检测量。2D 为无高度的俯视地图；3D 使用固定 50° 俯仰角与 -18° 方位角。切换模式时复位缩放，下钻保留所选模式；进入区域时预加载目标边界和统计，其他板块向外退出、所选板块放大，随后显示下一级地图；通过面包屑返回时播放缩小与归位的反向过渡。初次加载及刷新采用渐显，3D 板块从平面浮起；日期切换时高度和填色从当前显示状态同步插值到新数据，中途再次切换也不复位。填色仅由数据决定，不受临时高亮和轮巡影响；边界和板块共用高度插值，不再对轮廓顶点作飞线过渡。锁定时仅按钮缩放与点击下钻，解锁开放鼠标拖拽平移与滚轮/双指缩放，保持 2D/3D 既定倾斜角度；复位同时恢复平移位置与缩放。名称不再横向避让，优先保留高亮及阳性区域标签；被浮起板块挡住的无阳性区域名称及相互重叠的低优先级名称暂时隐藏，遮挡消失并等待板块动画结束后恢复。系统开启减少动态效果时停止轮巡动画和过渡。WebGL 不可用时回退二维区域图。

全国显示省界，下钻依次显示市、区县，区县为最细层级；直辖市直接显示区县。趋势和热力图保持完整报告月份，地图和指标跟随当前时段。


WebMCP 提供只读的 `read_surveillance_summary` 工具（浏览器支持时注册）；本机环境未进行 WebMCP 调用验证，不影响常规界面使用。

## 后续院内部署

已有域名 `sentry.floatnoise.com` 的线上版本仍待数据库切换；新部署默认只绑定回环端口。院内多人访问时可由反向代理提供 HTTPS 并转发到本机前端端口，数据服务继续仅监听回环地址；后台已支持管理员与超管账号；后续可按医院要求增加机构权限隔离。使用 HTTPS 代理时，设置 `SENTRY_SECURE_COOKIE=1`，并通过 `SENTRY_TRUSTED_ORIGINS` 明确配置管理端域名（多个域名以逗号分隔）。不要直接开放 API 端口。

静态检查排除未修改的 shadcn 组件目录。React Compiler 的同步 effect 提示作为建议警告（本项目未启用 React Compiler）；业务代码保留类型检查、可访问性及正确性规则。

启动生产版本后运行 `npm run test:smoke`，检查页面、API 及地图下钻接口。该回归检查覆盖生产转发响应头必须可修改的框架约束。
